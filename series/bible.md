# Series Bible — *Lantern Lane* (working title)

> Placeholder series to show how the pipeline works. Change the names, world and tone to your own show;
> the pipeline reads only the YAML files, so this document is for the writers' room.

## Logline
Pip, a small, curious repair-bot, runs a lantern workshop at the end of a crooked lane. Each episode,
a neighbour brings in something broken, and fixing it teaches Pip (and the audience) something new.

## Format
- **Audience:** ages 6–10, with something for the grown-ups watching alongside
- **Runtime:** 3–5 minute shorts (an AI-generated shot runs about 3–5 s, so plan 40–80 shots)
- **Structure:** Cold open → The problem → Try & fail → The insight → Fix & payoff → Button gag

## Tone
Warm, gently funny, never mean. The jokes come from curiosity, not from mocking anyone.

## World rules
1. Lanterns glow according to the mood of whoever holds them.
2. Pip cannot climb stairs, so the lane is full of ramps Pip built.
3. Nobody is a villain. Problems come from misunderstandings, weather or physics.

## Recurring cast
See `characters/`. Each character file holds the **visual description used in every prompt**, so keep it
consistent; it is what keeps a character looking the same from shot to shot.
